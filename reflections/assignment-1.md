# Assignment 1 Reflection

## What was the breakthrough that moved the work forward?

The biggest breakthrough was realising that my first idea worked in code but did not work as an experience. My first prototype used a button counter that showed one wrong result. I wanted this to make the user question whether they could trust the system, but it mostly looked like a bug.

Instead of trying to make the same trick more obvious, I changed the core mechanic to calibration. The system now asks the user to set or answer something about the world, accepts the response, and moves on. This gave me much more room to develop the idea. The tasks could start with simple things and slowly move towards boundaries, reference and viewpoint without directly explaining the Brain in a Vat thought experiment.

## What did this work change about who I want to be as a software developer?

This project made me think less about whether an interaction simply "works" and more about what the user understands from it. The first counter prototype was technically correct, but that did not make it a good design.

I want to be a developer who is willing to test an idea, notice when the result does not communicate what I intended, and change direction instead of only polishing the code. Working with a coding agent also made this more important. The agent can build and change things very quickly, but I still need to decide what should be built, judge the result, and keep the whole experience moving in one clear direction.
